Microcontroladores e IoT

IoT / Automação

ATA Eletrônica: O Fim das Listas de Chamada em Papel

Um sistema embarcado desenvolvido para modernizar e automatizar o registro de frequência acadêmica. O dispositivo opera através de uma Máquina de Estados Finitos (FSM) robusta, garantindo segurança e agilidade.

Funcionamento: O professor autentica-se e configura a sessão. O aluno digita sua matrícula, o sistema valida no banco local e confirma a presença visualmente. Ao final, o ESP32 compila os dados e envia um relatório .CSV formatado automaticamente por e-mail via Wi-Fi.

Hardware & Tech: ESP32 DevKit V1, Teclado 4x4, LCD 16x2 I2C, LittleFS (Flash), SMTP/SSL (Email).
Wireless / Segurança

Telemetria Segura com Redundância e Correção de Erros

Implementação de um sistema de transmissão sem fio de alta confiabilidade entre Arduino e ESP32. O foco deste projeto foi a integridade dos dados em ambientes ruidosos.

Utilizando módulos NRF24L01+, implementei algoritmos de Hamming Code para correção automática de erros de bit. O protocolo customizado inclui handshake, verificação de "Magic Byte" e modos de economia de energia. O sistema conta ainda com simulação de "Jamming" para testes de stress e logs automáticos enviados periodicamente por e-mail.

Hardware & Tech: Arduino Uno (Tx), ESP32 (Rx), NRF24L01+, Sensor LDR, Algoritmo Hamming(15,11), Log em Flash.
Instrumentação

Lab Digital: Gerador de Funções, Frequencímetro e Analisador

Conjunto de ferramentas de bancada desenvolvidas do zero, integrando múltiplas plataformas de hardware para análise de sinais.

O projeto utiliza Raspberry Pi Pico, Arduino e ESP32 em conjunto com interfaces móveis (celular) para visualização de ondas e espectro de frequência, substituindo equipamentos caros por soluções acessíveis e programáveis.

SaaS / Microsserviços

Rota-S AI: Otimização Logística Urbana

Projeto de TCC focado na resolução do complexo "Problema do Caixeiro Viajante" (TSP). Trata-se de uma aplicação Full Stack que substitui o planejamento manual por rotas inteligentes, utilizando algoritmos híbridos de otimização.

Destaques da Arquitetura: O sistema opera sobre uma infraestrutura de microsserviços containerizados, integrando um Motor de Roteamento Próprio (OSRM) e banco de dados espacial para máxima precisão geográfica.

Stack: React, TypeScript, Python (FastAPI), Docker, PostgreSQL (PostGIS), Nginx.
